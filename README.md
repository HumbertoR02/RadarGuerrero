# RadarGuerrero
Radar Guerrero es un medio comprometido con el análisis crítico y la difusión de información veraz, oportuna y precisa sobre los acontecimientos más relevantes en Guerrero. Nuestro enfoque se centra en la cultura, la política y los temas sociales que impactan a la ciudadanía.

## Sistema de gestión de documentos
Se incorporó un sistema de gestión de documentos en la página principal para almacenar información en el navegador (`localStorage`) y separar los archivos en dos tipos:

- Notas periodísticas.
- Documentos administrativos.

Cada registro guarda título, descripción y fecha para facilitar la consulta rápida de archivos.
